## Deoxys-CTF-Writeups

A repository dedicated to documenting solutions, exploit scripts, and methodology for various Capture The Flag (CTF) competitions.

### Categories
This repository primarily focuses on the following domains:

* **Reverse Engineering (Rev):** Analyzing compiled binaries, understanding control flow, and bypassing protections using static and dynamic analysis.
* **Web Exploitation:** Identifying and exploiting vulnerabilities in web applications, including injection, broken authentication, and server-side misconfigurations.
* **Open Source Intelligence (OSINT):** Gathering and analyzing publicly available information to solve investigative challenges.
* **Forensics:** Investigating digital artifacts, memory dumps, network captures, and file system images to recover hidden data.

All scripts and writeups provided in this repository are for educational and ethical hacking purposes only. Use of these materials for unauthorized access to systems is strictly prohibited.
